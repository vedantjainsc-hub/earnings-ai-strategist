# Examples

Reviewed company case studies will live here.

Each example should contain:

```text
company-name/
├── README.md
├── source-manifest.csv
├── evidence-ledger.csv
├── opportunity-scores.csv
├── executive-memo.pdf
└── review-notes.md
```

## Publication rules

- Use public information and link to original sources.
- Quote only the passages needed to support the analysis.
- Do not republish complete licensed transcripts.
- State the company, ticker, fiscal period, publication dates, and analysis date.
- Say clearly that the analysis is independent and not company-endorsed.
- Include counter-signals, assumptions, and missing internal evidence.
- Do not publish a memo until every quotation has been checked manually.
