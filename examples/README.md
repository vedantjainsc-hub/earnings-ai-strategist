# Examples

This directory contains independent public-data demonstrations produced with the Earnings to AI Strategist workflow.

## Available cases

- [PepsiCo Q2 2026](pepsico/): order-fill exception prioritization pilot hypothesis.
- [JPMorgan Chase Q2 2026](jpmorgan-chase/): AI use-case evidence and portfolio review pilot hypothesis.

Each case includes a shareable PDF, editable DOCX, accessible Markdown memo, and structured citation ledger. The analyses are not affiliated with or endorsed by the companies. They are strategy hypotheses for internal validation, not claims about production readiness or current operating deficiencies.

Future examples should contain:

```text
company-name/
├── README.md
├── source-manifest.csv
├── evidence-ledger.csv
├── opportunity-scores.csv
├── executive-memo.pdf
└── review-notes.md
```

## Publication rules

- Use public information and link to original sources.
- Quote only the passages needed to support the analysis.
- Do not republish complete licensed transcripts.
- State the company, ticker, fiscal period, publication dates, and analysis date.
- Say clearly that the analysis is independent and not company-endorsed.
- Include counter-signals, assumptions, and missing internal evidence.
- Do not publish a memo until every quotation has been checked manually.
